# Identidad del Proyecto

## Propósito
Plataforma web para Vyktor Nexus, centrada en la recopilación y distribución de recursos, tutoriales y herramientas avanzadas para el sector AEC (Arquitectura, Ingeniería y Construcción), con fuerte énfasis en BIM e IA.

## Framework
[Next.js 15.1.4](https://nextjs.org/) (App Router)

## Arquitectura Técnica
- **Arquitectura**: Next.js App Router (Híbrida: SSR/ISR/Client components).
- **Frontend**: React 19 + TypeScript.
- **Estilos**: Tailwind CSS 3.4 + Ant Design 5.29.
- **Animaciones**: Framer Motion.
- **Fase Actual**: Migración de HTML estático a Next.js.

## Stack
- **Core**: Next.js, React, TypeScript.
- **UI**: Ant Design, Tailwind CSS.
- **Icons**: Lucide React, Ant Design Icons.
- **Animations**: Framer Motion.

## Usuario Objetivo
Profesionales del sector AEC, especialistas BIM, ingenieros y arquitectos que buscan optimizar sus procesos mediante tecnología e IA.

## Nivel de Madurez
Active Development (Fase de migración y expansión de contenido).

## Decisiones Arquitectónicas
- Migrar de un sitio basado en HTML estático a un framework moderno (Next.js) para mejorar el SEO y la mantenibilidad.
- Uso de Ant Design para componentes complejos y Tailwind para diseño visual a medida.
- Implementación de una estética "Dark Mode Premium" para las secciones principales (Nexus).
- Separación de documentación en `_docs/` para memoria persistente.
